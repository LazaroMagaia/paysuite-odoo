PaySuite Payments

Accept M-Pesa, e-Mola, mKesh and card payments in Odoo through the PaySuite checkout.

Overview

This module adds PaySuite as a payment provider in Odoo. Customers are redirected to the PaySuite checkout, choose their payment method there, and return to Odoo once the payment is complete. Transactions are updated automatically from PaySuite notifications.

It works with any Odoo flow that uses payment providers, such as eCommerce checkout, invoice payments and payment links.

Features

  • Redirect checkout through the PaySuite hosted payment page.
  • Payment status is confirmed directly with the PaySuite API, not only from the data received in the browser.
  • Webhook endpoint that validates the X-Signature header (HMAC-SHA256) using your webhook secret.
  • Optional sync of customers as PaySuite contacts: the customer is looked up by email and created if not found.
  • Phone numbers are converted to international format (Mozambique +258 by default).
  • Payment references are cleaned to the characters PaySuite accepts.
  • Supports the MZN currency only.

External service required

This module needs a PaySuite company account with API access. Personal PaySuite accounts do not include API access. Payments are processed by PaySuite, not by this module or by Odoo.

Configuration

  1. Generate an API token in your PaySuite merchant dashboard (Settings, API Access).
  2. In Odoo, open Accounting, Configuration, Payment Providers and select PaySuite.
  3. Enter the API token and the webhook secret.
  4. Make sure the web.base.url system parameter is the public HTTPS address of your Odoo, so PaySuite can reach the webhook.
  5. Set the provider to Enabled (or Test Mode).

How it works

  1. The customer selects PaySuite at checkout.
  2. Odoo creates a payment request in PaySuite and redirects the customer.
  3. The customer pays on the PaySuite page.
  4. PaySuite sends the customer back to Odoo and notifies your Odoo by webhook.
  5. Odoo verifies the signature, checks the payment status with the PaySuite API and updates the transaction.

Data privacy

The module communicates with the PaySuite API to create and check payments. For each payment it sends the amount, a payment reference, a short description and the return and webhook addresses of your Odoo.

Customer contact sync is optional and disabled by default. If you enable "Sync Customers as PaySuite Contacts" on the provider, the customer's name, email address and phone number are also sent to PaySuite, to find an existing contact by email or to create a new one. If the option is disabled, none of this personal data is sent. The module does not collect usage statistics and does not send data to any other service.

Please make sure that your own privacy policy covers the processing of customer data by PaySuite.

Requirements

  • Odoo 20 (Community or Enterprise), on-premise or Odoo.sh. Custom modules cannot be installed on Odoo Online (SaaS).
  • A PaySuite company account with an API token and a webhook secret.
  • A publicly reachable HTTPS address for your Odoo, for webhook delivery.
